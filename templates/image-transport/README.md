# Cloud PNG text transport

Copy decode_project_image.py to the project's tools/ and decode-image.yml to .github/workflows/. Adapt the target-build step to the project. Copy tests to tests/. Generate the image with image generation, encode the unchanged bytes as canonical ASCII base64 in bounded files project-overview.png.b64.000 onward. A manifest at docs/images/project-overview.manifest.json contains bytes, dimensions [width,height], SHA256, and ordered chunks filenames. Commit all chunks and workflow in one branch commit. The workflow validates and writes the PNG, deletes transport chunks and uses ephemeral GITHUB_TOKEN with contents: write to push the same branch. It executes final tests explicitly because token pushes may not automatically trigger new push workflows. No skip-ci marker. Verify final head gates and tree before merge. Existing project repositories never require repository-creation capability. Never duplicate an existing project PR or force-push.
